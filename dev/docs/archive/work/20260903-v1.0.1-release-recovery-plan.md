## 2. Recovery decision

[`dev/docs/version-management.md`](../../../../dev/docs/version-management.md) §8.3に従い、共有済み`v1.0.0`を修正または再利用せず、新しいPATCH版`v1.0.1`へ移行する。同じrunのrerun、`v1.0.0`への再dispatch、main-only workaroundによる`v1.0.0`公開は禁止する。

## 4. Guardrails

- `v1.0.0` tag、failed run、logを変更しない。
- Releaseを検出した場合は重複dispatchしない。
- `v1.0.1`のRelease作成前にrepository immutabilityを再取得する。
- `/sample/`、workbook本文、private path、credential、full raw logをcommit/uploadしない。
- canonical sampleはexact pathだけを使用し、同directoryを列挙して代用しない。
- optional live Copilot／Excel recalculationをrequired gateへ合算しない。
- 各task後に独立した敵対的reviewを行い、実在するfindingだけを反映して再検証する。
- failure時は次phaseへ進まず、Release/tag/assetを差し替えない。
